What it does

Core capabilities

Ensemble prediction

LSTM + XGBoost + Random Forest

Combines a sequence model with two tree-based models, improving directional accuracy over any single baseline.

Feature engineering

5+ technical indicators

RSI, ADX, MACD, Bollinger Bands, and ROC engineered as model inputs alongside raw price history.

Accuracy

~72% directional accuracy

~12% lower prediction error than baseline single-model approaches, measured across the covered stock set.

Coverage

50+ Indian stocks

Real-time charting and technical analysis across a broad set of NSE/BSE-listed names.

Dashboard

Interactive Streamlit interface

Custom prediction requests, live charts, and technical-analysis views in a single interactive dashboard.

Accounts

Auth & watchlists

User authentication and personal watchlists backed by SQLite, so predictions and preferences persist per user.
